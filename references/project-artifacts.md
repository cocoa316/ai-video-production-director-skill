# 项目记录文件

项目跨越多个 Cut、多次生成、多个会话或多人协作时使用。一次性的简单提示词不必创建。

```text
.ai-video/
  project-brief.md     项目概要
  music-map.md         音乐项目使用
  cut-table.md         分镜与制作状态
  storyboard.md        视觉故事板版本、用途与审查，需要时使用
  asset-registry.md    素材与引用职责
  decision-log.md      关键决定
  result-log.md        实际生成结果
```

```markdown

- 类型：叙事表演 / 制作总览 / 动作空间控制 / 混合
- 视觉精度：白模 / 同角色低渲染 / 精细导演板
- 对应故事版本：
- 对应 Cut：
- 当前版本与状态：
- 文件位置：
- 负责维度：
- 禁止迁移：
- 审查结论：
- 需复查的下游内容：
```

只有项目实际使用视觉故事板时才创建。普通对话中的故事板提示词不需要单独保存为文件。

## `cut-table.md`

```markdown
| Cut | 成片时长 | 生成时长 | 职责 | 开始状态 | 可见事件 | 运镜 | 结束状态 | 转场 | 素材 | 状态 |
|---|---:|---:|---|---|---|---|---|---|---|---|
```

状态使用：`计划中`、`素材制作中`、`可生成`、`已生成`、`已采用`、`偏差采用`、`返修`、`废弃`、`已剪辑`、`已交付`。

## `asset-registry.md`

```markdown
| 素材 | 类型 | 版本 | 状态 | 负责维度 | 禁止带入 | 使用 Cut | 位置 |
|---|---|---|---|---|---|---|---|
```

引用状态明确写为：`仅供分析`、`灵感参考`、`实际生成引用`或`已弃用`。

## `decision-log.md`

```markdown
| 日期/轮次 | 范围 | 决定 | 原因 | 替代对象 | 需复查的下游内容 |
|---|---|---|---|---|---|
```

只记录影响未来工作的决定，例如缩短项目、改变风格、弃用引用、拆分镜头或将生成过渡改为硬切。

## `result-log.md`

```markdown
| Cut/尝试 | 预期结果 | 实际结果 | 决定 | 接受的尾部状态 | 下一步 |
|---|---|---|---|---|---|
```

“实际结果”必须来自可检查的成片，或明确标记为用户描述，不能从提示词推测。

在项目结构变化、Cut 增删重排、引用启用或弃用、高成本生成获批、结果被接受/废弃、会话结束或需要交接时，更新受影响的文件即可，不要每轮重写全部记录。
