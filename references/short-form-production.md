# 短视频制作方法

适用于约 5～30 秒、以单一情境、互动、笑点、情绪反转或视觉表演为核心的内容。

## 一条短视频先锁定五件事

1. **观众为什么愿意继续看**：第一秒的角色、情境或动作钩子。
2. **本条只完成什么**：一个关系变化、一个笑点或一次视觉展示。
3. **角色为什么这样行动**：动作和反应必须有触发原因。
4. **观众从哪里观看**：景别、机位、距离和是否采用主观视角。
5. **最后停在哪里**：包袱、反应、画面落点或下一条的引子。

## 参考视频的两条工作路线

### 高度复刻

逐段分析事件、动作、表情、运镜、声音和剪辑。更换角色、语言或场景后，检查这些变化是否破坏原片成立的条件。

### 结构改编

先完整分析原片，再保留真正有效的机制，如误解结构、情绪递进、视角关系或结尾反转；重新设计文化语境、对白、场景和人物行为。

路线由用户与 Agent 共同决定，不默认“复刻”或“原创”必然更好。

## 时间分配

先做简要时间表，再写生成提示词：

| 时间 | 信息/对白 | 可见动作 | 表情反应 | 运镜 | 声音 |
|---|---|---|---|---|---|

对白不能占满全部时长。为理解、停顿、反应和笑点留出空间。出现吞音、抢话或表演过急时，优先缩短台词、换易发音表达、增加停顿或拆段，而不是只写“说清楚”。

## 表演链

复杂表演按因果顺序设计：

```text
初始状态 → 外部触发 → 察觉 → 表情/视线变化
→ 决策 → 主要动作 → 结果 → 余韵或反应
```

惊讶、流泪、笑容、灵光一现等状态必须在触发后出现。需要突然性时，不要让准备动作提前泄露结果。

## 镜头与角色距离

短视频里人物大小会显著影响代入感。对话或恋爱互动通常需要让角色更接近观众；奔跑和冲撞的速度感需要摄影机与主体运动配合。使用主观视角时，还要明确视线高度、手部进入画面的方式和摄影机是否代表另一角色。

## 声音设计

- 明确谁在何时说话，避免声线互相污染。
- 规定无声区间，不让参考视频的声音无意转移。
- 声音形容要稳定复用，但不能保证模型生成完全相同声线。
- 无对白短片仍可需要呼气、抗议声、碰撞声或机械声来支撑表演。
- 文字显示若必须由模型生成，需评估准确率；可以后期完成时优先后期。

## 生成次数与拆段

一次生成承载不了所有对白、动作和镜头变化时，可以拆为多段。拆段前确认：

- 是否需要视觉连续；
- 是否只是剧情连续而无需引用上一条视频；
- 使用上一条视频会不会带入不需要的声音、动作或画风；
- 切点是否有自然停顿或镜头变化；
- 是否应抽取尾帧，还是重新建立下一镜头。

## 发布前检查

- 开头是否立即可理解；
- 梗或情绪是否无需额外背景解释；
- 台词对目标语言受众是否自然；
- 动作触发、反应和结果是否清楚；
- 运镜是否帮助表达而非干扰；
- 结尾是否有明确落点；
- 声音、字幕、文案与作品人设是否一致。
