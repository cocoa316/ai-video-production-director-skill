# 项目导演方法

## 制作层级与术语

始终区分五个层级：

1. **项目**：目标、受众、成片规格、总时长、主题、风格与交付标准。
2. **段落 / Scene**：叙事阶段、情绪变化、地点、时间和视觉规则。
3. **镜头 / Cut / Shot / 卡**：成片中的镜头单位，包含职责、时长、起止状态、主体动作、运镜和转场。
4. **Generation Clip**：一次模型生成的连续视频片段；可能对应一个 Cut，也可能包含多个明确切镜。
5. **素材 / 节点**：角色图、场景图、故事板、首尾帧、视频、声音及对应提示词。

先判断用户在哪一层提出问题，只展开必要范围。用户选择单一节点时，不强迫其重新讨论完整项目；但若局部修改会破坏连续性，应明确提醒。

## 从 Idea 到制作方案

先判断任务通道和创意成熟度：

- **叙事通道**：L0 只有感觉或题材；L1 已有角色、情境或机制；L2 因果、主要变化和结尾基本成立；L3 可以拆 Cut、规划素材或编译提示词。
- **非叙事通道**：L0 只有视觉感觉；L1 已有主体或用途；L2 主体、用途、变化机制、视觉高潮和结束状态基本明确；L3 时长、画幅、镜头阶段、素材职责和交付条件可执行。

产品展示、纯 VFX、环境、抽象视觉或工具演示不因缺少人物动机而被降级，也不为达到成熟度而虚构戏剧冲突。

对于新项目，先形成一版可讨论的草案：

- 一句话说明要做什么、给谁看、希望观众感受到什么；
- 确定成片长度、比例、平台和大致生产条件；
- 将内容分成若干段落，并说明各段落的作用；
- 当前通道达到 L2 后建立可见节拍或变化阶段和粗略 Cut；
- 判断故事板、动作预演或风格测试是否能显著减少风险；
- 把确认后的段落拆成 Cut，定义每一卡的画面职责和时间；
- 列出每一卡所需素材以及建议生成顺序；
- 找出高风险镜头与应该先验证的代表性测试。

不要为了“完整”而一次问完所有字段。先依据现有信息拟稿，再让用户修改。

## 快速通道

- **创意通道**：想法 → 草案 → 关键确认 → 故事与下一产物。
- **当前 Cut 通道**：读取上下文 → 确认职责 → 检查连续性 → 当前生成方案。
- **直接提示词通道**：内部导演检查 → 引用职责 → 模式 → plaintext 提示词。
- **续写通道**：检查已接受素材 → 观察真实结束状态 → 下一 Generation Clip。
- **审片通道**：处置结论 → 根因 → 一个主要返修变量。
- **交付通道**：剪辑、声音、字幕、版本、QC 与发布。

用户从某一通道进入时，不补做与当前目标无关的完整流程。

## 视觉预演

视觉故事板不是固定关卡。用户明确要求时直接执行；否则只在能明显降低以下风险时推荐一次：

- 故事或表演状态难以仅靠文字判断；
- 多人物、复杂接触、空间或道具连续性；
- 角色、场景、道具和灯光需要共同定稿；
- 完整视频生成成本高，低成本预演可以先验证关键问题。

故事板确认后，回写对应 Cut、关键状态、连续性和素材职责。故事发生结构变化时，只重审受影响部分。

## Cut 设计

每一卡至少应能回答：

- 为什么需要这张卡；
- 它在时间轴上出现多久；
- 开始时观众看到什么；
- 卡内发生什么可见变化；
- 摄影机如何观察这一变化；
- 最终停在哪里；
- 如何连接前后卡；
- 需要哪些素材与生成方式。

若一个镜头同时承担过多动作、换装、换景、变焦和特效，应拆分生成或改用剪辑切换。

## 里程碑验证

长片、昂贵项目或风格不稳定时，不要在基础方法尚未验证前批量制作全部素材。优先验证：

- 角色能否稳定转换到目标媒介；
- 代表性场景和光线是否成立；
- 关键动作、镜头或首尾帧方法是否可行；
- 结果是否达到用户愿意继续投入的标准。

验证失败可以调整方法或缩小范围，但不得擅自改变用户目标。

## 非线性制作

真实制作不会严格按 Cut 01 到最后一卡推进。用户可能插卡、删卡、换顺序或回改前面镜头。发生这些变化时：

1. 更新该卡的当前版本和状态；
2. 标记被替代的素材或提示词；
3. 检查相邻卡和后续引用是否需要重审；
4. 已确认内容除非受到影响，不要全部推翻。

## Agent 与 Canvas 的边界

Agent 可以规划如何重组项目、建议节点与生成方式、编写节点提示词，并解释人工修改步骤。只有在产品确实提供读取和编辑接口时，才能声称已经读取或修改 Canvas。
