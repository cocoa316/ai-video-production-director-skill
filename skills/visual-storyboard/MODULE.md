# Visual Storyboard

本模块是制作导演内部的视觉预演工具。它不替代创意协作，也不直接决定最终视频提示词。

它与 Seedance 的 Dense Storyboard Mode 不同：本模块生成供人或视频模型参考的故事板图；Dense Storyboard Mode 组织一次视频生成中的多镜头或连续阶段。多格故事板不自动代表多次切镜。

## 进入条件

用户明确要求故事板时直接进入。主动推荐时，当前通道至少应达到 L2：叙事通道的因果、主要变化和结尾基本成立；非叙事通道的主体、用途、变化机制、视觉高潮和结束状态基本明确。

故事不足时返回创意发展阶段，只询问会改变故事方向的关键问题。

## 先判断用途

- **导演讨论板**：供人审阅故事、构图、表演和节奏，可以有较精细角色。
- **视频生成执行板**：将上传给视频模型，默认使用同角色低渲染或身份中性的白模，降低材质、五官、文字和版式迁移。
- **制作总览板**：统一角色、场景、道具与灯光资产；不能让总览区挤压主要分镜。

## 选择控制目标与视觉精度

不要把 A、B、C 当成互斥枚举。分别判断：

1. 主要控制目标：叙事表演、制作总览、动作空间连续性，或组合。
2. 视觉精度：通用白模、同角色低渲染、精细导演板。

常用预设：

- A：线稿叙事板，强调情绪、视线和故事可读性。
- B：白模制作总览，强调角色、场景、道具和灯光统一。
- C：动作空间控制板，强调站位、方向、接触、重心和道具状态。
- A＋C：同时需要情绪表演和动作连续性。
- B＋C：同时需要资产总览和空间控制。

详细方法见[视觉故事板方法](../../references/visual-storyboard-method.md)。实际生成前必须读取[故事板生成与交接合同](../../references/storyboard-generation-contract.md)。

## 工作流

1. 确认创意版本、叙事或非叙事通道、目标时长、单格目标画幅和故事板用途。
2. 按因果和状态变化拆关键节点；格数由时长与动作密度决定。
3. 区分关键状态、真实切镜和一次生成内的连续阶段。
4. 选择控制目标、视觉精度、颜色策略、格数和网格；根据单格画幅计算整板画布比例。
5. 建立角色、场景、道具和视角连续性。
6. 按生成合同编写图像提示词；精确尺寸、严格画幅、高密度或曾发生版式失控时优先逐格生成后确定性合成。
7. 用户要求实际生成时，调用当前可用的图像生成工具；精确编号和说明默认在图像生成后添加，不依赖图像模型拼写。
8. 检查实际文件尺寸、整板与单格比例、颜色、格数、角色、空间、动作、道具、编号和版式。
9. 用单变量返修主要问题。
10. 用户确认后，输出故事板交接合同并回写对应 Cut、素材职责和视频提示词计划。

## 引用职责

生成故事板时，角色参考只负责身份、比例、标志轮廓和服装结构；故事负责事件和情绪；本模块负责拆解、构图、版式和连续性。

故事板进入视频生成时，明确它只负责哪些维度，以及不得迁移的线稿、灰阶、白模、简化五官、画框、编号、文字和整板排版。角色、声音和成片材质由项目中另行指定的权威素材负责。

## 输出契约

按用户当前需要返回：

1. 选择的故事板用途、控制目标和视觉精度，以及一句理由；
2. 用户需要时提供可复制的图像生成提示词；
3. 用户要求实际生成时提供故事板图片；
4. 生成后的尺寸、比例、颜色、格数和连续性审查结论，以及一个主要返修变量；
5. 用于视频模型时的完整故事板交接合同，包括 panel-to-Cut 映射、允许继承、禁止继承、角色与声音权威素材、道具起止状态。

默认直接给 plaintext，不主动生成 `.txt`。用户只要求提示词时，不强制输出其余内部分析。
